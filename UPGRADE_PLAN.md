# Gela Upgrade Roadmap

The upgrades are intentionally delivered and verified one phase at a time. Dynamic spoken app names and command history are excluded.

1. Single-instance protection — complete
2. Dedicated `%LOCALAPPDATA%\Gela` storage with migration — complete
3. Microphone, sleep, and audio-device recovery — complete
4. Diagnostics and live status window — complete
5. Wake-word calibration wizard — complete
6. One automatic command retry without repeating the wake word — complete
7. Interruptible voice responses — safe manual interruption complete; speech barge-in deferred pending echo cancellation
8. Application and window control — complete
9. Additional safe Windows controls — complete
10. Media playback controls — complete
11. User-defined multi-action routines — complete
12. Flexible local intent recognition — complete
13. Optional local question answering — complete
14. Optional online service modules — complete
15. Installer, upgrade-in-place updates, clean uninstall, and final packaging — complete

Windows Hello, PIN, and password replacement remains outside the implementation plan because voice alone is not secure authentication.
