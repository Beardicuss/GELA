# Support

Use GitHub Issues for reproducible defects and feature proposals. Before filing
a recognition issue, include the GELA version, Windows version, microphone name,
the exact phrase spoken, and the sanitized relevant log lines.

Do not publish secrets, full personal logs, home-network details, or absolute
paths containing a personal username. Security reports belong in the private
channel described in `SECURITY.md`.

GELA is currently a Windows-focused project developed by Softcurse Systems.
